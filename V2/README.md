# EEG Robot V2

> **Status: In development**

V2 is the ongoing independent redevelopment of the original EEG Robot following completion of the V1 undergraduate project.

Development is focused on improving the drivetrain, sensing, embedded control, telemetry, EEG processing and overall system architecture.

The original completed system is preserved under [`../V1/`](../V1/).

Documentation and source files will be added here as V2 subsystems are implemented and validated.
